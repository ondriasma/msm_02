Instalace a spuštění

1. Otevřete složku projektu ve Visual Studio Code.
2. Vytvořte virtuální prostředí `.venv` a nainstalujte potřebné knihovny z `requirements.txt`.
3. Otevřete soubor `main_fish.ipynb`.
4. V pravém horním rohu klikněte na Select Kernel a vyberte Python z vytvořeného prostředí `.venv`.
5. Spusťte jednotlivé buňky notebooku nebo zvolte Run All.
